درباره من
مهندس نرم‌افزار هستم و از اردیبهشت ۱۴۰۳ در کرمان موتور روی سامانه‌های سازمانی کار می‌کنم؛ از برنامه‌ریزی تولید، کنترل کیفیت ، ثبت مقاطع تولیدی، مهندسی ابزار و سیستم مجوز دهی تا گزارش‌گیری، پورتال داخلی و اپلیکیشن کارکنان. بیشتر کارم با C#، ASP.NET Core و SQL Server است و پروژه‌های وب و موبایل را با React، Next.js، React Native و Node.js انجام می‌دهم. کارهایی را دوست دارم که مشکل واقعی یک سازمان را حل می‌کنند، مثل سریع‌کردن یک گزارش کند یا بازنویسی یک سیستم قدیمی. این روزها روی اتوماسیون با n8n و ساخت ایجنت‌های هوش مصنوعی هم کار می‌کنم.

اردیبهشت ۱۴۰۳ - تاکنون
  • توسعه و نگهداری سامانه MIS با C# و ASP.NET Core برای کرمان موتور، خودروسازان بم و کارمانیا؛ شامل ماژول‌های برنامه‌ریزی تولید، کنترل کیفیت، مهندسی ابزار، ثبت مقاطع تولیدی، روابط عمومی، ماژول مجوز دهی و تنظیم دسترسی و گزارش‌های حجیم و هوشمند. با این کار گزارش‌های ماهانه سریع‌تر آماده می‌شوند و خطای ورود اطلاعات کمتر شده است.
  • بازنویسی وب‌سرویس‌های قدیمی که داده‌های سیستم تولید کرمان موتور و خودروسازان بم را به سیستم فروش در تهران می‌فرستند. با مدیریت بهتر خطاها و امن‌ترکردن ارتباط، سرویس‌ها پایدارتر شدند.
  • بازطراحی سیستم گزارش‌گیری قدیمی که روی میلیون‌ها رکورد کار می‌کرد. با بهینه‌سازی کوئری‌ها و انتقال گزارش‌های سنگین به پردازش پس‌زمینه، زمان ساخت گزارش‌ها خیلی کمتر شد.
  • بازنویسی پورتال داخلی کرمان موتور و شرکت‌های زیرمجموعه با ASP.NET Core MVC و Repository Pattern. دسترسی به سامانه‌های داخلی، ورود کارکنان و اطلاعیه‌ها و رویدادهای روابط عمومی حالا از یک پنل مدیریت می‌شود.
  • توسعه فرانت‌اند اپلیکیشن موبایل خدمات کارکنان برای کرمان موتور و خودروسازان بم، که پرسنل کارخانه بم و دفتر مرکزی تهران از آن استفاده می‌کنند.
